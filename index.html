서명 검증된 사이트 계정만 자기 비공개 자료를 조회할 수 있습니다. 아래 버튼은 익명 접근, 내 계정 조회, 다른 계정 조회 거절, 거절 전후 건수, URL 계정 번호 위조를 실제 HTTP 요청으로 확인합니다. 비공개 본문은 기록에 출력하지 않습니다.

카드 4 · 기기를 잃어버렸을 때

패스키 추가 및 계정별 관리

카드 5 · 두 번째 사이트 계정 준비

카드 4를 유지하려면 owner 계정의 horse와 horse2를 모두 보존해야 합니다. 카드 5의 다른 계정 owner2에는 별도의 세 번째 패스키가 필요합니다. 기존 키는 이동하거나 삭제하지 않습니다.

기존 두 패스키를 유지하며 새 패스키 하나를 추가합니다. 실제 성공 전에는 카드 5가 완료되지 않습니다.

PIN 입력 필수 아님: 이 사이트는 등록과 로그인에서 PIN을 필수로 요구하지 않습니다. 다만 Google·Windows·Bitwarden 등 패스키 관리자가 자체 잠금 해제를 요구할 수 있습니다. 별도 PIN 없이 사용 가능할지는 인증기 정책에 달려 있으며 서버는 서명을 검증합니다. Google 계정 추가나 Chrome 프로필 변경 없이 아래 패스키 추가 등록 버튼에서 바로 시작할 수 있습니다.

선택 사항 · 기존 패스키 로그인

로그인하지 않았어도 아래의 새 패스키 이름과 저장 위치를 미리 선택할 수 있습니다. 패스키 추가 등록을 누르면 기존 패스키로 본인 확인한 뒤 새 등록을 진행합니다.

패스키 추가 화면은 항상 열려 있습니다. 정보를 먼저 입력하고 등록을 누르면, 필요한 경우에만 기존 패스키로 로그인합니다. 계정에 새 공개키를 저장하기 전에는 반드시 본인 인증이 필요합니다.

패스키 목록 확인 중…

패스키에는 이 사이트용 비밀번호가 필요하지 않습니다. 삭제할 때 이전 로그인 세션이 15분 이상 지났다면 기존 패스키로 다시 본인 인증하고 삭제를 이어갑니다. 이름이 같은 패스키는 ID 일부와 등록 날짜로 구분합니다.

로그인한 뒤 목록을 조회할 수 있습니다.

패스키가 하나도 남지 않으면 로그인할 수 없으므로 마지막 1개 삭제는 서버에서 차단합니다.

새 패스키 등록 · 언제든 시작 가능

이미 Google 계정이 2개 있다면: 아래 저장 위치에서 「다른 Google 계정(B)에 패스키 저장」을 선택한 뒤 기존 등록 버튼 하나만 누르세요. 별도 USB나 새 Google 계정은 필요 없습니다.

이름과 저장 위치는 로그인하지 않았어도 입력할 수 있습니다. 등록 버튼을 누르면 필요할 때 기존 horse로 인증하고 새 패스키를 생성합니다. 기존 패스키는 삭제되지 않습니다.

기본 owner의 horse와 horse2는 그대로 유지하고, 카드 5에서 세 번째 패스키를 만들면 별도 사이트 계정 owner2가 독립적인 자료실을 갖습니다. Google 계정 B에 저장하려면 Chrome에서도 B 프로필을 사용해야 합니다. 현재 Google 관리자가 자체 PIN을 요구하는 것은 사이트에서 강제로 제거할 수 없습니다.

기존 horse는 그대로 두고, 새 horse2마다 다른 WebAuthn 등록 ID를 발급합니다. Google 계정을 추가하거나 USB 보안 키를 연결할 필요는 없습니다. 실제 잠금 해제 창은 브라우저가 관리합니다.

카드 4 · 다른 Google 계정으로 등록

Google 계정 B에 두 번째 패스키 저장

Google 이메일을 선택하는 버튼은 WebAuthn에 없습니다. 대신 Chrome 프로필 A(기존 horse)에서 5분짜리 등록 링크를 발급하고, 그 링크를 Google 계정 B로 로그인한 별도 Chrome 프로필에서 열어 새 패스키를 생성할 수 있습니다. 등록한 패스키는 현재 로그인된 사이트 계정에 연결됩니다.

등록 권한이 있는 일회성 링크입니다. 5분 안에 계정 B의 Chrome 프로필로 이동하세요. 링크를 다른 사람에게 공유하지 마세요.

순서: ① 계정 A 프로필에서 위 버튼으로 링크 발급 ② Chrome 오른쪽 위 프로필 메뉴에서 계정 B로 전환 ③ B 프로필 주소창에 링크 붙여넣기 ④ B의 Google 비밀번호 관리자에서 새 패스키 생성.
