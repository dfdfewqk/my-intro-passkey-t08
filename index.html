카드 4 · 기기를 잃어버렸을 때

두 번째 패스키 추가 및 관리

선택 사항 · 기존 패스키 로그인

로그인하지 않았어도 아래의 새 패스키 이름과 저장 위치를 미리 선택할 수 있습니다. 패스키 추가 등록을 누르면 기존 패스키로 본인 확인한 뒤 새 등록을 진행합니다.

패스키 추가 화면은 항상 열려 있습니다. 정보를 먼저 입력하고 등록을 누르면, 필요한 경우에만 기존 패스키로 로그인합니다. 계정에 새 공개키를 저장하기 전에는 반드시 본인 인증이 필요합니다.

패스키 목록 확인 중…

로그인한 뒤 목록을 조회할 수 있습니다.

패스키가 하나도 남지 않으면 로그인할 수 없으므로 마지막 1개 삭제는 서버에서 차단합니다.

새 패스키 등록 · 언제든 시작 가능

이름과 저장 위치는 로그인하지 않았어도 입력할 수 있습니다. 등록 버튼을 누르면 필요할 때 기존 horse로 인증하고 새 패스키를 생성합니다. 기존 패스키는 삭제되지 않습니다.

기존 horse 패스키는 그대로 보존합니다. 같은 Google 비밀번호 관리자에 동기화된 키는 두 개로 세지 않습니다. 기존 저장소가 중복으로 거절된다면 다른 휴대전화 · QR코드를 먼저 시도할 수 있습니다. 저장 장치 선택은 브라우저에 요청하지만 실제 장치·Google 계정을 강제로 지정할 수는 없습니다.

주의: Windows가 USB 보안 키를 요구하면 휴대전화 인증이 아닙니다. USB가 없으면 취소하세요. 사이트에서 QR 창을 강제로 열 수 없으며, 해당 PC에서 QR을 지원하지 않으면 휴대전화 자체에서 사이트를 열어 등록해야 할 수 있습니다.

패스키 이름과 저장 위치를 선택한 뒤 「패스키 추가 등록」을 누르세요. 기존 패스키 인증이 필요하면 등록 과정에서 안내합니다.
